<h2 id="english">🇬🇧 English</h2>

Thank you for your interest in contributing to TomatoClock!

### How to Contribute

1.  **Fork & Clone**: Fork the repository and clone it to your local machine.
2.  **Create a Branch**: Create a new branch for your feature or bug fix (`git checkout -b feature/your-feature-name`).
3.  **Code & Test**: Make your changes. Ensure you follow the architecture rules defined in `REQUIREMENTS.md` and that all tests pass (`./gradlew testDebugUnitTest connectedDebugAndroidTest`).
4.  **Commit**: Write clear, descriptive commit messages.
5.  **Pull Request**: Submit a PR against the `main` branch. Provide a detailed description of your changes.

### Reporting Bugs & Requesting Features
Please use the provided GitHub Issue templates to report bugs or request new features. Provide as much detail as possible to help us reproduce or understand the issue.

<h2 id="中文">🇨🇳 中文</h2>

感谢您有兴趣参与 TomatoClock 的贡献！

### 如何贡献代码

1.  **Fork 与 Clone**：首先 Fork 本仓库，然后克隆到您的本地机器。
2.  **创建分支**：为您的新功能或 Bug 修复创建一个新的分支 (`git checkout -b feature/your-feature-name`)。
3.  **编码与测试**：进行代码修改。请确保您的代码遵循 `REQUIREMENTS.md` 中的架构规范，并且所有的测试都能顺利通过 (`./gradlew testDebugUnitTest connectedDebugAndroidTest`)。
4.  **提交代码**：编写清晰且具有描述性的提交信息。
5.  **提交 PR**：向 `main` 分支提交 Pull Request，并在 PR 中详细描述您的更改内容。

### 报告 Bug 与功能请求
请使用我们提供的 GitHub Issue 模板来报告 Bug 或请求新功能。请提供尽可能多的细节，以帮助我们重现或理解您的问题。
